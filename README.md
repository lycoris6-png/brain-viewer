# 脳断面ビューア

CT・T1・T2・FLAIR・MRA の断面と、回転できる 3D 脳・主要動脈を連動させて見比べるブラウザ用ツールです。

- 標準データは、解剖を単純化して計算で作った**教材用の模擬ファントム**です。実際の患者画像ではなく、診断には使えません。
- NIfTI(`.nii` / `.nii.gz`)を開くと自分のデータも表示できます。処理はすべてブラウザ内で行い、外部へは送信しません。

## ファイル
- `brain-viewer.html` … 編集する正本(HTML の断片)
- `index.html` … `sh build.sh` で正本を包んだ公開用ページ(GitHub Pages が配信)

3D 表示に three.js r128 を jsDelivr から読み込むため、表示にはネット接続が必要です。
